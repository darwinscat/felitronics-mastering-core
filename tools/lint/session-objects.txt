# WHAT felitronics::session's OBJECT FILES MAY CONTAIN beyond code — read by modules/session/tests/object-gates.cmake,
# which reads every object of the library and of the C boundary (tools/wasm/fc_session.cpp) with this row's own
# symbol-table reader and asks two questions the object file answers exactly:
#   1. which symbols live in WRITABLE memory — mutable state with static storage, however it was spelled (a direct
#      initialiser, a static inside a lambda, a macro, an asm label, a const object that needs a constructor at start-up);
#   2. which symbols are CALLED that nothing in the set defines — printf, fopen, time, getenv, strtod, isalpha, rand,
#      whatever header they arrived through and however they were named, called or taken by pointer.
# The answer to 1 must be nothing (the C boundary: exactly the globals named below). The answer to 2 must match a line
# below. Every other symbol is refused, and the refusal names it.
#
# Format (one per line; the reason is required):
#   global     <scope>  <name>     <why>   a writable symbol allowed BY NAME, matched against its demangled name; each must
#                                           be found EXACTLY once in the objects of its scope, or the list has rotted
#   writable   <scope>  <regex>    <why>   writable symbols allowed by pattern (instrumentation, a toolchain's own)
#   undefined  <scope>  <regex>    <why>   called symbols allowed by pattern, matched against the symbol's name (Mach-O's
#                                           leading underscore removed)
# <scope>: all · elf · macho · coff · wasm · san (only when FELITRONICS_ENABLE_SANITIZERS is on) · coff-debug (only an
# MSVC build in its Debug configuration, /MDd — the debug runtime's own calls, which exist in no other build) · facade
# (only the C boundary's objects) · facade-<format>. Patterns are CMake regular expressions.

# --- the C boundary keeps these two, and nothing else keeps anything
global     facade  g_slots        the handle table: a handle must name a session between two calls
global     facade  g_callState    the poison flag: it must outlive the call that never returned
